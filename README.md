# StockTrigr

Backend em NestJS que monitora uma lista fixa de ativos da B3, calcula indicadores (Bollinger, RSI, Fibo BB) em ciclos periódicos e envia alertas pelo Telegram quando um gatilho é atingido.

## Stack

NestJS · TypeScript · SQLite · Telegram Bot API
